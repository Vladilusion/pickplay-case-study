# Guidance for repository contributors and coding agents

- This is a public portfolio repository, not the PickPlay production repository.
- Never add credentials, secrets, customer or user data, database dumps, proprietary source code, or production configuration.
- Keep all documentation in professional technical English.
- Keep examples small, self-contained, deterministic, and clearly labelled as illustrative.
- Treat any new code as illustrative unless it is explicitly marked otherwise.
- Do not assert that proposed controls or roadmap items already exist in production.
- Run relevant Markdown, link, Mermaid, language-syntax, and consistency validation before proposing changes.
- Prefer small, reviewable commits with descriptive messages.
